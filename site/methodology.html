Methodology

The pipeline classifies the recorded owner name on each residential tax lot, then measures stock, sales, and whether a natural person appears on linked filings. Full rules and ADRs live in the repository.

Owner classes

One class per owner record. First matching rule wins (RULES_VERSION 2026-09-16.2). Entity-owned = llc + corp + partnership. Trusts are a sensitivity series and are not in the headline. Public and nonprofit owners leave the private denominator before shares are computed. Co-op buildings are identified by official building class, not by name.

Stock

Current snapshot: DCP PLUTO 64uk-42ks version 26v2, residential lots only (ADR 0003). Neighborhoods are 2020 NTAs via hm78-6dwm (bct2020 → boroct2020). Shares are parcel-weighted and unit-weighted. NTA cells with fewer than 10 residential units have shares nulled.

Corrected headlines use Rogan–Gladen on the held-out gold test split (n=305). Citywide p_hat is treated as a census; uncertainty is from gold sensitivity and specificity only.

Flow and history

ACRIS Master / Legals / Parties. Headline sale deeds: DEED, DEED, RC, DEEDP, DEEDO, REIT, ASTU (ADR 0005). Flow keeps document_amt ≥ $10,000. History uses all named sale deeds. Coverage window is recorded years 2003–2025 (ADR 0006). Buyer class is name-only. Property borough is Legals borough.

Opacity

O1 if HPD HeadOfficer / IndividualOwner / JointOwner / Officer / Shareholder has a first and last name, or a NY DOS chairman name classifies as an individual. O2 if a cluster parent is O1. O4 if the chain is entities only. O3 is the residual no-person set (ADR 0007). Clustering uses entity owner keys only; Agent / SiteManager / Lessee are never person-links or exact-name hubs; addresses are evidence, not edges (ADR 0008).

What is published

Citywide and NTA-or-coarser aggregates. oh publish refuses owner keys, person names, addresses, and parcel files. There are no entity or portfolio pages.
